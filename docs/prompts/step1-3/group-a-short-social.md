# Step1-3 媒体アドオン A（短文速報型: X / Facebook / Instagram）

この入力は短文SNS投稿です。以下の観点を**共通プロンプトに上書き追加**して判定してください。

## 重点
- 短文で断片情報が多いため、**情報実体の有無**を最優先で見る
- リンク/固有名詞/バージョン/比較結果/具体手順がある投稿を優先
- 感想のみ・煽りのみ・既知技術の誇張のみは noise 寄り

## ノイズ寄せ条件（SNS強化）
- 「すごい」「やばい」だけで根拠なし
- コメント的な一言のみ（実体なし）
- 参照先がなく、再現可能性ゼロ

## 残すべき信号
- 需要供給の生の声（例: 乗り換え報告、不満、採用実績）
- 実運用の失敗/成功談（短文でも具体性があれば残す）

## 既知技術の扱い
- 既知技術の誇張のみは noise 寄り
- ただし「社会的に普及済みだが自社未導入」の技術は、目新しさが低くても `EVAL` 候補として残す

## 媒体別メモ
- X: 日米の注目トピックの初速が出やすい。速報性重視
- Facebook: 海外実務コミュニティの実例・共有が多い
- Instagram: 実演/提供側投稿が多く、短文でも実体リンクは重視
