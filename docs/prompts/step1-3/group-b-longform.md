# Step1-3 媒体アドオン B（長文解説型: YouTube / Qiita / Reddit / Google Alerts / RSS）

この入力は長文・解説系コンテンツです。以下の観点を**共通プロンプトに上書き追加**して判定してください。

## 重点
- **再現性**（手順、コード、設定、比較条件）があるか
- **新規性**（既知情報のまとめだけでないか）
- **実務価値**（導入・検証に使えるか）

## 高評価シグナル
- 具体的な手順/検証結果/失敗学
- API/MCP/ツール導入の実践知
- 新機能の利用方法や比較レビュー

## ノイズ寄せ条件
- 長文だが中身が薄い（主張のみ、具体性なし）
- AI文脈が弱い一般論
- 記事体裁のみで一次情報や根拠が乏しい

## 媒体別メモ
- Qiita: 実装・再現手順がある投稿を優先
- Reddit: Q&A/議論混在。愚痴のみはnoise、具体解決策は採用
- YouTube: チュートリアル/新ツール紹介は `APPLY` 候補
- Alerts/RSS: 信頼性・一次情報導線の有無を重視
