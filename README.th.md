## เคยเจอแบบนี้ไหม?

ถ้าข้อไหนตรงกับคุณสักข้อ X Collector ถูกสร้างมาเพื่อคุณ

- คุณตามข่าว AI ทั้งบน X, Reddit, GitHub และอีกเป็นสิบเว็บไซต์ — แต่ก็ยังพลาดประกาศใหญ่ ๆ
- การไล่เช็กทุกแหล่งกินเวลาวันละชั่วโมง แถมส่วนใหญ่ก็เป็นเรื่องเดิมซ้ำ ๆ
- คุณบอกไม่ได้แล้วว่าบัญชีที่ติดตามอยู่ บัญชีไหนยังคุ้มค่าที่จะติดตาม
- ผู้ช่วย AI ของคุณตอบคำถาม "สัปดาห์นี้เกิดอะไรขึ้นบ้าง?" จากแหล่งข้อมูลที่*คุณ*เชื่อถือไม่ได้

สาเหตุร่วมนั้นง่ายมาก: **ข่าวไม่เคยมาถึงในที่เดียวแบบจัดระเบียบแล้ว** X Collector จะรับงานรวบรวมและคัดแยกนี้ไปทำแทนคุณ

## ทำอะไรได้บ้าง

4 ขั้นตอน ตามลำดับนี้เสมอ

```mermaid
flowchart LR
    A["① รวบรวม<br/>จากแหล่งข้อมูล 8 ประเภท"] --> B["② จัดระเบียบ<br/>จัดหมวดหมู่และเชื่อมโยง"]
    B --> C["③ จัดพิมพ์<br/>หนังสือพิมพ์วันละฉบับ"]
    C --> D["④ ส่งถึง<br/>คนและ AI เอเจนต์"]
```

- 📥 **รวบรวม**

  รวบรวมข่าวสารจาก X (Twitter), Instagram, Facebook, Reddit, Qiita, GitHub และฟีด RSS/YouTube คุณเป็นคนเลือกแหล่งข้อมูลทุกแหล่งเอง

- 🗂️ **จัดระเบียบ**

  จัดทุกรายการเข้าหมวดหมู่ เชื่อมโยงข่าวซ้ำและข่าวต่อเนื่องเข้าด้วยกัน และให้คะแนนว่าช่วงหลังแต่ละแหล่งข้อมูลน่าเชื่อถือแค่ไหน

- 📰 **จัดพิมพ์**

  จัดหน้าข่าวที่คัดเลือกแล้วเป็นหนังสือพิมพ์ 13 คอลัมน์ ทุกวัน โดยอัตโนมัติ

- 🤖 **ส่งถึงคนและ AI พร้อมกัน**

  คุณอ่านหนังสือพิมพ์และฟีดที่ค้นหาได้ผ่านเว็บ ส่วน AI เอเจนต์ของคุณอ่านข้อมูลชุดเดียวกันเป๊ะ ๆ ผ่าน API และเซิร์ฟเวอร์ MCP (มาตรฐานกลางที่ให้เครื่องมือ AI เชื่อมต่อกันได้)

- ✅ **คนเป็นผู้ตัดสินใจเสมอ**

  ระบบเสนอแหล่งข้อมูลใหม่ที่น่าสนใจที่มันค้นพบได้ แต่จะไม่มีอะไรถูกเพิ่มเข้าคอลเลกชันของคุณโดยที่คุณไม่ได้อนุมัติอย่างชัดเจน

## ต้องมีอะไรบ้าง

แค่ 3 อย่าง ตารางความเข้ากันได้ฉบับเต็มอยู่ใน[เอกสารสำหรับวิศวกร](docs/engineering.md#supported-environments) (ภาษาอังกฤษ)

- **ที่สำหรับรันระบบ** — คอมพิวเตอร์ของคุณเองหรือเซิร์ฟเวอร์ ที่มี Node.js 20 ขึ้นไป
- **ฐานข้อมูล PostgreSQL** — ที่เก็บรายการข่าวที่รวบรวมมา
- **API key เฉพาะฟีเจอร์ที่คุณใช้เท่านั้น** — ดูตารางด้านล่าง

| สิ่งที่อยากทำ | สิ่งที่ต้องมี |
|---|---|
| เข้าสู่ระบบหน้าเว็บ | ข้อมูลรับรอง Google OAuth (ฟรี) + อีเมลที่อนุญาตให้เข้าสู่ระบบ |
| รวบรวมจาก X, Instagram, Facebook, Reddit | key ของ [ScrapeCreators](https://scrapecreators.com/) |
| จัดหมวดหมู่ด้วย AI และเรียบเรียงหนังสือพิมพ์ | key ของ [OpenRouter](https://openrouter.ai/) |
| เพิ่มบทถอดเสียง YouTube ลงในข่าว | key ของ [TranscriptAPI](https://transcriptapi.com/) (ไม่บังคับ) |
| รวบรวมจาก Qiita, GitHub, RSS | ไม่ต้องใช้ key |

เรื่องค่าใช้จ่าย: Google OAuth จำเป็นสำหรับการเข้าสู่ระบบ แต่ฟรี — มันเป็นวิธีล็อกอิน ไม่ใช่ API แบบเสียเงิน ส่วน ScrapeCreators และ OpenRouter เป็นบริการแบบเสียเงินตามการใช้งานจริง (pay-as-you-go) ราคาปัจจุบันดูได้จากเว็บไซต์ของแต่ละเจ้า ถึงไม่มี key แบบเสียเงินเลย แอปก็เริ่มทำงานได้ เข้าสู่ระบบได้ และรวบรวมจากแหล่งข้อมูลที่ไม่ต้องใช้ key ได้ — เพียงแต่ขั้นตอนที่ใช้ AI (การจัดหมวดหมู่และหนังสือพิมพ์รายวัน) จะยังปิดอยู่จนกว่าคุณจะเพิ่ม key ของ OpenRouter และจะเพิ่ม key ทีหลังทีละตัวก็ได้

## เริ่มต้นใช้งาน

### ให้ AI เอเจนต์ติดตั้งให้

ถ้าคุณใช้ AI coding agent (Claude Code, Codex CLI และเครื่องมือทำนองเดียวกัน) วิธีที่เร็วที่สุดคือส่ง repository ให้มันจัดการ:

```text
ช่วยติดตั้ง https://github.com/caty-ai/x-collector บนเครื่องนี้ให้หน่อย
ดูจาก .env.example แล้วพาฉันตั้งค่าที่จำเป็นไปทีละขั้นตอน
```

เอเจนต์จะ clone ติดตั้ง แล้วถามคุณเฉพาะค่าที่มันตัดสินใจแทนคุณไม่ได้ เช่น ที่อยู่ฐานข้อมูลและ key สำหรับเข้าสู่ระบบ ถ้าคำถามข้อไหนตอบไม่ได้ ก็บอกมันไปตรง ๆ ได้เลย — การเตรียมฐานข้อมูล PostgreSQL และการตั้งค่า Google OAuth ก็เป็นเรื่องที่เอเจนต์พาคุณทำไปทีละขั้นได้เหมือนกัน

### ติดตั้งด้วยตัวเอง

ขั้นที่ 1 — ดาวน์โหลดและติดตั้ง:

```bash
git clone https://github.com/caty-ai/x-collector.git
cd x-collector
npm install
cp .env.example .env
```

ขั้นที่ 2 — เปิด `.env` ด้วยโปรแกรมแก้ไขข้อความอะไรก็ได้ แล้วกรอกค่าที่จำเป็น 6 ค่าแรกใช้สำหรับฐานข้อมูลและการเข้าสู่ระบบ ส่วน 2 ค่าสุดท้ายทำให้หน้าฟีดและหน้าหนังสือพิมพ์ใช้งานได้:

```dotenv
DATABASE_URL=postgresql://user:password@localhost:5432/x_collector
AUTH_SECRET=replace_with_a_long_random_secret
AUTH_GOOGLE_ID=your_google_oauth_client_id
AUTH_GOOGLE_SECRET=your_google_oauth_client_secret
NEXTAUTH_URL=http://localhost:3000

# บัญชี Google ที่อนุญาตให้เข้าสู่ระบบ (คั่นด้วยคอมมา)
# ถ้าปล่อยว่างไว้จะไม่มีใครเข้าสู่ระบบได้เลย
ADMIN_EMAIL_ALLOWLIST=you@example.com

# สำหรับการติดตั้งบนเครื่องเดียว ให้ชี้แอปมาที่ตัวมันเอง
# และตั้ง key สุ่มยาว ๆ ขึ้นมาเองได้เลย
RAILWAY_API_BASE_URL=http://localhost:3000
FEED_API_KEY=any_long_random_string_you_issue_yourself
```

ขั้นที่ 3 — เริ่มระบบ:

```bash
npm run migrate
npm run dev
```

เปิด `http://localhost:3000` เข้าสู่ระบบ แล้วลงทะเบียนแหล่งข้อมูลของคุณที่ `/settings` หรือถ้าอยากลองใช้ทันทีด้วยแหล่งข้อมูลตัวอย่าง ให้รัน `npm run seed` หนึ่งครั้งแทน เมื่อ key สำหรับรวบรวมข้อมูลพร้อมแล้ว ให้เปิดหน้าต่างเทอร์มินัลที่สองขึ้นมา แล้วรันการรวบรวมด้วย `npm run collect`

<details>
<summary>ถ้ามีอะไรผิดพลาด</summary>

<br>

**`command not found: npm`**

ยังไม่ได้ติดตั้ง Node.js ดาวน์โหลดได้จาก [nodejs.org](https://nodejs.org/) (เวอร์ชัน 20 ขึ้นไป) จากนั้นเปิดเทอร์มินัลใหม่แล้วลองอีกครั้ง

**เชื่อมต่อฐานข้อมูลไม่สำเร็จ**

ตรวจสอบว่า PostgreSQL กำลังทำงานอยู่ และผู้ใช้ รหัสผ่าน กับชื่อฐานข้อมูลใน `DATABASE_URL` มีอยู่จริง ขั้นตอนที่คนลืมบ่อยที่สุดคือยังไม่ได้สร้างฐานข้อมูลชื่อ `x_collector` ก่อน

**การเข้าสู่ระบบด้วย Google ขึ้นข้อผิดพลาด**

ข้อมูลรับรอง Google OAuth สร้างได้ฟรีใน [Google Cloud Console](https://console.cloud.google.com/) (APIs & Services → Credentials → Create credentials → OAuth client ID) จากนั้นตรวจสอบว่า `NEXTAUTH_URL` ตรงกับที่อยู่ที่คุณเปิดในเบราว์เซอร์ และ redirect URI ของ OAuth ที่ลงทะเบียนไว้บน Google Cloud คือ `http://localhost:3000/api/auth/callback/google`

**การเข้าสู่ระบบด้วย Google ขึ้น `AccessDenied`**

บัญชี Google ของคุณไม่ได้อยู่ใน `ADMIN_EMAIL_ALLOWLIST` ให้เพิ่มที่อยู่หลักที่แสดงบน myaccount.google.com (อีเมล Gmail ที่มีจุดหรือเครื่องหมายบวกต่างกันจะถือเป็นคนละที่อยู่) จากนั้นรีสตาร์ทแอป

## ทำไมถึงวางใจได้

X Collector ถูกออกแบบมาไม่ให้ระบบอัตโนมัติแอบเข้าควบคุมอะไรเงียบ ๆ

- **แหล่งข้อมูลใหม่ทุกแหล่งต้องผ่านการอนุมัติจากคุณ** — แหล่งที่ระบบค้นพบจะถูกให้คะแนนและนำเสนอเท่านั้น มีแต่คนเท่านั้นที่เลื่อนขั้นให้มันได้
- **แหล่งข้อมูลที่เพิ่มเองด้วยมือจะไม่ถูกหยุดอัตโนมัติ** — การปลดระวางอัตโนมัติใช้กับแหล่งที่ระบบค้นพบเองเท่านั้น และต้องผ่านการตรวจรายสัปดาห์ 2 ครั้งติดต่อกันก่อนด้วย
- **คุณภาพของแหล่งข้อมูลถูกให้คะแนนทุกวัน** — คะแนนความน่าเชื่อถือมีผลต่อการจัดอันดับในหนังสือพิมพ์ และข่าวจากแหล่งที่ความน่าเชื่อถือต่ำหรือยังไม่ผ่านการตรวจสอบจะมีป้ายเตือนกำกับไว้ ไม่ถูกนับเป็นข่าวน่าเชื่อถือแบบเงียบ ๆ
- **ช่องทางของเอเจนต์เป็นแบบอ่านอย่างเดียว** — เซิร์ฟเวอร์ MCP ค้นหาและอ่านได้เท่านั้น เปลี่ยนแปลงอะไรไม่ได้เลย
- **หนังสือพิมพ์เป็นแบบส่วนตัวโดยค่าเริ่มต้น** — มีแต่คนที่คุณอนุญาตเท่านั้นที่อ่านได้ การเปิดให้สาธารณะเข้าถึงคือสวิตช์ที่คุณต้องเปิดเองอย่างชัดเจน
- **ข้อมูลของคุณเป็นของคุณ** — ระบบรันบนเซิร์ฟเวอร์ของคุณเองและฐานข้อมูลของคุณเอง ภายใต้สัญญาอนุญาต MIT

- **ระดับความพร้อม**: ไปป์ไลน์หลักใช้งานจริงในระบบโปรดักชันทุกวันและได้รับการดูแลอย่างต่อเนื่อง
- **ข้อจำกัดที่ทราบ**: คอลเลกเตอร์ที่เชื่อมต่อแพลตฟอร์มภายนอกต้องใช้ข้อมูลรับรอง API ของคุณเอง และจะไม่ถูกรันใน CI

รันการตรวจสอบด้วยตัวเอง: `make test` / `make lint` (ครอบ `npm test` และการตรวจสอบ TypeScript — ดู [CONTRIBUTING](CONTRIBUTING.md))
